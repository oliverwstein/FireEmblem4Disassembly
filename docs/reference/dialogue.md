## State (`aDialogue`) and text rendering

1. `rlResetDialogueEngine` clears `aDialogue` (`wStatus`, `wCommandCycle`, `wPauseTimer`, `bFontPage`, `wSlotOffset`), sets up the 2bpp font (`g2bppDialogueFont`) and width table (`aDialogueFontWidth`), and initializes two dialogue slots (`_Slot[0]` at VRAM `$8000 >> 1` / `$7E840E`, `_Slot[1]` at `$9000 >> 1` / `$7E878E`).
2. Each frame, `rlRunDialogueCycle` (or `rlRunDialogueCycleAndSprites`, which also updates portrait overlay sprites and A-press arrows via `rsDisplayDialogueSlotAPressArrows`) advances the active script at `aDialogue.lActivePointer` unless paused by `wPauseTimer`.
3. `rsDialogueRenderNextCharacter` combines `bFontPage` with the character byte, draws the glyph into the 2bpp character buffer (`rsDialogueLoadCharacterGraphicIntoBuffer`), and advances pixel/VRAM offsets using `aDialogue.lFontWidthTable` (`rsDialogueAdvancePixelOffset`). `rsDialogueUploadPendingTiles` plays the text sound and uploads pending tiles to VRAM.
4. `rlAdvanceDialogueOnButtonPress` clears `DialogueStatusWaitForInput` or fast-forwards `wPauseTimer` (`$FFFF`) unless `DialogueStatusPreventASpeedUp` is set.
5. `hdmaDialogueBG3Scroll` (HDMA channel 4, `rlDialogueCreateBG3ScrollHDMA`) and `rlDialogueUpdateHDMATable` split `BG3HOFS`/`BG3VOFS` across the active dialogue box rows.

## Boxes, portraits, and backgrounds

- **Four modes (`aDialogue.wMode`, `DIALOGUE_MODE_*` in `include/Dialogue.h`):** mode 0 has no boxes or portraits (castle name pop-ups, battle scene quotes, world map, save menu); mode 3 is a keeper's box (shops, arena, augury, class change), and Start can't skip it; mode `1` uses map dialogue boxes (`rlDialogueOpenMapSlotBox`, `rlDialogueCloseMapSlotBox`, and `rlRedrawDialogueBoxTilemaps` copying `$7FC54E`/`$7FC5B2` to the map menu buffer); mode 2, the conversation screen (`DIALOGUE_WITH_BG`, castle talks, credits), opens/closes its windows (`rlDialogueOpenConvBox*` / `rlDialogueCloseConvBox*`) and shows portraits via `rlConversationShowLeftPortrait` / `rlConversationShowRightPortrait`.
- **Portraits:** `rlDialogueLoadPortraitWaitMusic` / `rlDialogueLoadPortraitImmediate` resolve Gen 2 child replacements (`rlDialogueTryGetActiveChildCharacterID`), call `rlDecompressDialoguePortrait`, copy the 16-color palette to `aBGPaletteBuffer.aPalette6`/`7`, upload 16×4 4bpp tiles to VRAM `$7000`/`$7800` (`rsDialogueLoadPortraitData`), and write the 4×6 tilemap (`rsDialogueLoadPortraitWriteTilemap`, mirrored for slot 0 by `rsDialogueFlipSlot0PortraitTile`). While speaking, `rsDialogueUpdateMouthAnimation` cycles `aDialogueMouthAnimationFrames` and `rlUpdateDialoguePortraitOverlayTiles` / `rlUploadDialoguePortraitOverlayTiles` update the eye/mouth overlay tiles at VRAM `$ABC0`.
- **Backgrounds:** `aDialogueBackgroundPointers` stores five pointers per `DIALOGUE_BG_*` entry (foreground tiles at VRAM `$2000`, picture tiles at `$0000`, 256-color palette, foreground tilemap at `$7000`, and picture tilemap at `$7520`).

## Death quotes and inline scripts

- `rlGetMapBattleDeathQuote` and `rlCheckUsingDefaultOverLoverDeathQuote` select either a character's lover death quote (`aLoverDeathQuotes`, if their lover is alive) or default death quote.
- `rlRunInlineDialogueEventScript` copies `aMapDialogueEventTemplate` or `aSongAndDialogueEventTemplate` into `aEventScriptBuffer` and runs it via `rlStartEventScript`.

## Dependencies

- **Events & world map:** `rlSetDialogueActivePointer` (`CHANGE_DIALOGUE`), `procEventDialogueWithBG`, `procEventWaitDialogueEnd`, `rlInitWorldMapDialogueSlot` / `rlWorldMapDialogueHDMA` (`engine/events/event_scripts.asm`).
- **Castle & arena:** `rlDialogueStartTextAndHDMA` in mode 3 and `rsSetupKeeperDialogueBox` (`engine/castle/`, `engine/arena/arena.asm`).
- **Battle scene & map battle:** `rlDialogueFindPortraitIDInText` / `rlDialogueFindRawPortraitIDInText` (`engine/battle_scene/results.asm`), `rlGetMapBattleDeathQuote` and `rlRunDialogueCycleAndSprites` (`engine/battle/map_battle.asm`).
- **Map & menus:** `rlLoadBattleBannerGraphicsAndPalette` (`engine/map/phase_banner.asm`), `rlCoordsToTilemapOffset` and `rlClosePopUpWindowAndRestoreMap` (`engine/map/popups.asm`), `rlDialogueLoadAndDrawPortrait` (`engine/menus/item_list.asm`).
