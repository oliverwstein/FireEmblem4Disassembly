## Data structures and RAM pools

- **Implicit selected unit:** Nearly every routine reads `wSelectedUnitDataRAMPointer` (`$00/056F`, a 16-bit offset into bank `$7E` `aUnitRAMArea`), paired with `wCurrentClassDataROMPointer` (`$00/057A`, bank `$83` offset), `lRoutineVariable` (`$00/0571`), `wRoutineVariable1`–`3` (`$00/0574`–`$0578`), and `lRAMBufferPointer` (`$00/058D`).
- **Master directory and pools (`$7E/2180`–`$7E/3D86`):**
  - `aFactionArea` (`$7E/2180`, 195 bytes): 7 faction slots (`0..6`, `Factionless = 7`) + free-space offset. Each slot holds a 5-byte `structFactionHeader` (`GroupID`, `LocationID`, `HostileFactions`, `AlliedFactions`, `UnitCount`) followed by `UnitCount` 16-bit unit RAM pointers.
  - `aUnitRAMPointers` (`$7E/2243`): `structRAMStructHeader` + 72 word entries of active unit pointers.
  - `aUnitRAMArea` (`$7E/22D7`): 72 × 19-byte `structCharacterDataRAM` headers (`Type` byte + 6 far pointers: `PersonalData`, `ExtendedPersonalData`, `ConstantData`, `EnemyROMData`, `InventoryData`, `LoverData`).
  - `aStaticUnitRAMArea` (`$7E/29E7`): 24 slots of `Personal` (15B) + `Extended` (15B).
  - `aDynamicUnitRAMArea` (`$7E/2D4F`): 17 slots of `Personal` (15B) + `Extended` (15B) + `ConstantData` (22B).
  - `aHolyAndEnemyRAMArea` (`$7E/3131`): 63 slots of `Personal` (15B) only.
  - `aInventoryRAMArea` (`$7E/3664`): 73 (`72 + 1`) inventory blocks.
  - `aLoverRAMArea` (`$7E/3BD7`): 9 × 30-byte `structLoverDataRAM` blocks (15 words each, female player units `GenID 16..24`).
  - `aUnitWinCounts` (`$7E/3D23`): 24 Gen-1 words + 24 Gen-2 words (`$7E/3D53`). `wTotalLevelUpCount` (`$7E/3D83`), `wTotalAlivePlayerUnitCount` (`$7E/3D85`), `aUnitJoinOrder` (`$7E/531B`, 24 bytes).
- **Four `UnitType`s and their pointer layouts (`unit_creation.asm`):**
  - `UnitTypeStatic` (`0`): `Personal` + `Extended` in `aStaticUnitRAMArea`; `ConstantData` → ROM (`$83`, `+CharacterID`); `EnemyROMData = 0`; allocates `Inventory` + `Lover` (if female).
  - `UnitTypeDynamic` (`1`): `Personal` + `Extended` + `ConstantData` in `aDynamicUnitRAMArea`; `EnemyROMData = 0`; allocates `Inventory` + `Lover` (if female).
  - `UnitTypeHoly` (`2`): `Personal` in `aHolyAndEnemyRAMArea`; `ExtendedPersonalData` → ROM (`$83`, `+HP`); `ConstantData` → ROM (`$83`, `+CharacterID`); `EnemyROMData = 0`, `LoverData = 0`; allocates `Inventory`.
  - `UnitTypeEnemy` (`3`): `Personal` in `aHolyAndEnemyRAMArea`; `Extended = 0`, `Constant = 0`, `Lover = 0`; `EnemyROMData` → ROM (`$83`, `+CharacterID`); allocates `Inventory`.
- **Staging buffers (`$7F/EB4A`–`$7F/EC65`):** `aUnit1DataBuffer` and `aUnit2DataBuffer`, each holding word-widened `_Personal` (`structPersonalCharacterDataBuffer`, 28B), `_Extended` (`structExtendedCharacterDataBuffer`, 30B), `_ROM` (`structCharacterROMDataBuffer`, 34B), `_Inventory` (`structInventoryDataBuffer`, 20B), and `_Lover` (`structLoverDataRAM`, 30B). Marshalled by `rlSave*ToBuffer` / `rlLoad*FromBuffer` and `rlSaveSelectedUnitTotalStatsToBuffer`.

## Creation, lookup, and map spawning (`units.asm`, `unit_creation.asm`, `unit_data.asm`, `unit_info.asm`)

- **Lifecycle:** `rlLoadUnit` allocates a `structCharacterDataRAM`, appends to `aUnitRAMPointers`, calls `rlCreateUnit` (which dispatches via `aUnitCreationRoutinesByType`), and increments `wLoadedUnitCount`. `rlDeleteUnit` removes the unit from `aUnitRAMPointers`, undeploys it, clears `UnitStates`, and calls `rlClearSelectedUnitRAMAreaData` (which reverts owned `ItemStateInventory`/`ItemStateSupply` items via `rlRevertItemAcquirement` and frees pool blocks via `aRemoveUnitRAMAreaPointers`).
- **Lookups:** `rlGetUnitRAMDataPointerByID` scans `aUnitRAMPointers` by `CharacterID`; `rlFindCharacterByGenerationID` skips `Type >= UnitTypeHoly`; `rlGetUnitByCoordinates` scans `aDeploymentTable` backwards for `DeploymentStateAlive`; `rlGetCharacterDataROMPointer` indexes `aMainDataOffsets.CharacterDataOffsets` (bank `$83`).
- **Map spawning:** `rlLoadUnitGroup` walks a `$FFFF`-terminated `structUNITEntry` list, optionally swaps in a child ID (`rsLoadUnitGroupTryReplaceCharacterIDWithChild`), creates or reuses the unit, assigns its faction, binds to a placeholder slot (`rsDeployUnitByPlaceholderID`) or deploys (`rlDeploySelectedUnit`), sets AI, `UnitStateGroupLeader` (except `Civilian`/`Child`), castle-guarding on `TerrainCastle`, and `FormationID`. `rlLoadUNITGroupMapSprites` pre-registers sprites.
- **Range and target scanning:** `rlBuild32x32MapUnitGrid` fills a 32×32 grid centered on `(wR10, wR11)` with deployment offsets (`$FF` if empty). `rlFindTargetsInRange` walks Manhattan diamond rings `wR10..wR11` on `aRangeMap` using `aRangeDiamondStepDeltas` step deltas and runs one of 14 `aTargetFilterRoutines`; `rlCheckUnitPassesTargetFilter` checks a single unit (used for castle target lists).
- **Map sprites:** `rlGetSelectedUnitMapSprite` / `rsGetClassMapSprite` scans `aClassMapSpriteAssignmentOffsets` (`$83`) matching gender and `CharacterID` (or wildcard `0`, falling back to gender `$FF`).

## Classes, stats, skills, and weapon ranks (`classes.asm`, `stats.asm`, `skills.asm`, `unit_info.asm`)

- **Classes (`classes.asm`):** `rlGetClassDataROMPointer` stores the bank-`$83` offset in `wCurrentClassDataROMPointer`; 21 getters read class fields; `rlGetPromotedClassIfAvailable` rejects `UnitStateDismounted`, checks `aPromotionTable[CharacterID - 1]`, verifies `UnitLevel >= PromotionLevel`, and writes the flag and promoted class ID to `$7E/2000` and `$7E/2002`.
- **Stats and caps (`stats.asm`):**
  - Personal stat caps (`rlAddSelectedUnitStat._StatCaps`): **HP = 80**, **Str/Mag/Skl/Spd/Def/Res = 15**, **Luck = 30**.
  - `MaxHP = min(PersonalHP, 80)` (class base HP is not added; enemies use `rlGetEnemyMaxHP`).
  - `BaseStat = min(ClassBase + PersonalStat, 30)` for Str/Mag/Skl/Spd/Def/Res. `TotalStat` adds Holy Weapon boost (`WeaponStatBonus` `1..$0D` → `structHolyBloodDataEntry`), `SafeguardStatBoost` (`+7 Def`), `BarrierBladeStatBoost` (`+7 Res`), and `RingStatBonusBitfield` (`$80` Power, `$40` Magic, `$20` Skill, `$10` Speed, `$08` Shield, `$04` Barrier = `+5`; `$02` Leg = `+3 Mov`), which can exceed 30.
  - `TotalMovement` is `CantoMovement / 10` if `UnitStateCanto`, else `ClassMovement + (LegRing ? 3 : 0)`. `TotalFieldMovement` uses `_FieldMovementLookupTable` (`(Mov) * 10 + 1`, max `121`).
- **Skills (`skills.asm`):** 30 `SkillID`s (`$00..$1D`) map through `aValidPersonalSkillTable` (3B/entry), `aValidClassSkillTable` (2B/entry), and `aValidItemSkillTable` (2B/entry). `rlCheckIfUnitHasSpecifiedPersonalOrClassSkill` and `rlCheckIfUnitHasSpecifiedPersonalSkill` check personal/class bits; `rlCheckIfInventoryItemsHaveSpecifiedSkill` checks inventory slots (weapons must be equipped; rings are always active). `rlCollectSelectedUnitIconSkills` collects class + personal skills; `rlDebugGetSkillList` adds item skills.
- **Weapon ranks & Holy Blood (`unit_info.asm`):** 13 bloods (`0..12`) occupy 2 bits each in `HolyBlood1`/`HolyBlood2` (`Minor = 1`, `Major = 2`). `rlGetSelectedUnitWeaponRank` starts from the class rank (`A = 0, B = 1, C = 2, None = 3`); if `< 3`, Minor blood decrements the rank by 1 (`CLC`) and Major blood returns `A (0)` + `SEC` (★). `rlGetSelectedUnitTotal*Growth` computes `max(0, BaseGrowth + sum(BloodGrowth * (Major ? 2 : 1)))`.

## Unit state, gold, death, and turn-start effects (`unit_state.asm`, `turn_start.asm`)

- **HP, death, and revival:**
  - `rlActionStructInflictDamage` clamps damage to 80, sets `UnitStateMiracleActive` if surviving HP is `1..10`, and calls `rlActionStructHandleUnitDeath` (returning `SEC`) at 0 HP. `rlHealSelectedUnitsHP` clamps healing to 80 and caps at `MaxHP`.
  - `rlActionStructHandleUnitDeath` clears castle-guarding; in the arena (`wChapterFlags & $0010` and `wBattleType == 1`) calls `rlActionStructHandleArenaDefeat` (`HP = 1`, `DeploymentStateDefeated`); otherwise clears Canto and branches on `SkillIDEscape` (`UNIT_RELOCATION_ESCAPED`), `SkillIDPoW` outside Chapter 11 (`UNIT_RELOCATION_CAPTURED`, `StatusCaptive`), or death (`DeploymentStateDefeated` + `UnitStateDead`), then queues the death quote, increments `aUnitLossesCount`, and fires map event `$18`.
  - `rlReviveSelectedCharacter` places the unit in its faction's home castle (`rlSetUnitResidingInCastle`), clears defeat/sleep/moved/dead flags, restores `MaxHP`, and resets `ClassMoney`.
- **Gold, shops, supply, and castles:** Gold is capped at `50,000` (`rlAddSelectedCharacterMoney`); enemy `ClassMoney` is stored in units of 100 (6-bit max `6,300`G). `rlBuyItemForSelectedUnit` / `rlSellInventorySlotItem` / `rlDiscardSelectedInventoryItem` / `rlRepairSelectedUnitItem` handle castle transactions (Bargain halves buy/repair; holy weapons cannot be sold or discarded). `rlSendInventorySlotItemToSupply` moves items to `ItemStateSupply`; `rlGiveItemToUnitCheckEncumbered` sets `wInventoryFullDeploymentOffset` at 8 items; `rlActionStructArenaWinResults` awards `1000..4000`G across 7 rounds.
- **Turn-start effects (`turn_start.asm`):** `rlRunTurnStartEffectsForAllUnitsInFaction` dispatches by `Status` (`aTurnStartEffectsByStatus`):
  - `StatusHealthy` (`0`), `StatusSilence` (`4`), `StatusSleep` (`5`), `StatusBerserk` (`6`) run `rsGetTurnStartNormalEffect`, checking healing in strict priority order (first match wins): (1) `TerrainChurch` (full HP, 5G/HP, log type 2), (2) `SkillIDRecover` (full HP, free, type 3), (3) inside castle (20% `MaxHP` at 5G/HP for player, full/free for non-player, no map anim), (4) `UnitStateGuardingCastle` (20% `MaxHP` at 5G/HP, type 1), (5) `SkillIDRenewal` (`5 + rand(6)` = 5–10 HP, free, type 3). Player units with `< 5 * HP` gold partial-heal for `Money / 5` HP. Map animations are queued as 5-byte entries at `$7E/2004`.
  - `StatusCured` (`1`) restores `MaxHP` on expiry; `StatusFreelancer` (`2`) awards `3000`G on expiry; `StatusCaptive` (`3`) is a no-op.
  - `rlDecreaseFactionStatusDurations` decrements `StatusDuration`, clears `UnitStateMiracleActive`, wakes sleeping units (setting `wChapterFlags |= $0004`), and `rlUnsetFactionUnitsMoved` clears grayed/moved flags.

## Factions, allegiance, and join order (`factions.asm`, `join_order.asm`)

- **Faction slots (`0..6`, `FS_Player = 0`, `Factionless = 7`):** Bitmasks `$01..$40`. `rlInitiateFactionRAMData` resets all 7 slots; `rlLoadFactionGroup` populates group ID, locations, units, and home-castle placement; `rlUnloadFactionSlot` deletes non-dynamic units, sets dynamic units `Factionless`, and triggers `rlStartGameOverEvent` if slot 0 is unloaded.
- **Pairwise relations:** `rlGetFactionRelation` reads `HostileFactions` and `AlliedFactions` to return `0` (`AllegianceOwn`), `1` (`AllegianceEnemy`, also returned for invalid slots), `2` (`AllegianceAllied`), or `3` (`AllegianceNeutral`). `rlSetFactionHostility` updates both slots symmetrically and syncs `DeploymentAllegianceMask` (`$03`) on deployed units when slot 0 is involved.
- **Castle income:** `rlAddCastleMoneyToAllUnitsInFaction` gives `(AlliedCastles - 2) * 1000`G per living unit.
- **Join order (`join_order.asm`, bank `$8B`):** `aUnitJoinOrder` (`$7E/531B`, 24 entries indexed by `GenID - 1`) is updated by `rlAddToUnitJoinOrder` / `rlRemoveFromUnitJoinOrder` when units enter or leave `FS_Player`, and is used by `engine/menus/unit_window.asm` and `engine/save/save.asm`.

## Level-ups (`level_up.asm`)

- `rlActionStructLevelUp` accepts alive player `UnitTypeStatic`/`UnitTypeDynamic` units below level 30. At `EXP >= 100`, it subtracts 100 (or zeroes EXP and trims overflow at level 30) and calls `rlGetLevelUpStats`, which increments `Level` and `wTotalLevelUpCount` and fills `structLevelUpStats`.
- `rsRollForStatGrowth` supports `>100%` growths: grants `+1` if growth `>= 100`, subtracts 100 once, and rolls the remainder via `rlRollForChance` (max `+2` per stat per level), applying gains to personal stats capped at `80 / 15 / 30`.
- `rlAddWinToSelectedUnitAndWeapon` increments weapon `KillCount` and `aUnitWinCounts`. `rlDeploySelectedUnit` and `rlSetUnitUnfieldedInCastle` sit in `LevelUpSection` by bank-`$84` contiguity.

## Lovers, generation transfer, and inheritance (`lovers.asm`, `factions.asm`, `generations.asm`, `inheritance.asm`)

- **Lovers:** Female player units (`GenID 16..24`) own a 15-word `structLoverDataRAM` block in `aLoverRAMArea`. Bank-`$83` tables (`aMaleLoveDataIDs`, `aFemaleLoveDataIDs`, `aGen1LoveBases`/`aGen2LoveBases`, `aGen1LoveGrowths`/`aGen2LoveGrowths`) supply bases (`$FF` → `$FFFF` incompatible, `$FE` → `499`, else `byte * 10`) and signed growths. `rlModifyUnitsLovePoints` skips married women and `$FFFF` pairs, clamps at `0..500`, and at `500` calls `rlSetUnitsAsLoversByGenerationIDs` (sets mutual `LoverGenerationID`s and fires event action `$0011` with `Arg1 = female`, `Arg2 = male`).
- **Turn-start love (`rlAddTurnStartLovePoints` in `factions.asm`):** Runs on player phase for `wCurrentTurn < 51`. Adds per-turn growth against each present male (`rsAddLoveGrowthWithEachMan`), then adds `6 - distance` (`+5` at Manhattan distance 1) for adjacent living player units (`rsAddAdjacentLovePoints`).
- **Generation transfer (`generations.asm`):** `rlInitializeUnitRAM` clears unit/item/faction RAM on new game; `rlResetUnitsForChapter` runs at every chapter start. At `wCurrentChapter == 6`, it records parent permanent flags (`rlSetParentsPermanentFlags`), runs `rlDeleteParentsAndModifyChildrenData` over `aModifyChildrenDataList` (spawns children via `rlLoadChildUnit` and sets `aChildrenPermanentFlags`, deletes parents, transfers `Finn` to `AdultFinn` with half gold, applies `Seliph`/`Altena` overrides), and reverts `ItemStateShop`/`ItemStatePawnbroker` items. Substitutes are spawned later by chapter events when `PermanentFlag*Exists` is clear.
- **Inheritance (`inheritance.asm`):** Driven by `rsCreateDynamicUnitRAMData` with Mother in `aUnit1DataBuffer` (`wR1`) and Father in `aUnit2DataBuffer` (`wR0`):
  - **Growths (`rsGetChildGrowthRate`):** Male `Father + floor(Mother / 2)`; Female `Mother + floor(Father / 2)`.
  - **Skills:** `(Mother.Skills | Father.Skills) & aValidInheritableSkills[CharID - Seliph]`.
  - **Holy Blood (`rsGetChildHolyBlood`):** Minor-influence parent (`MajorInfluence == 0` means Mother is major, nonzero means Father is major) is downgraded (`Major → Minor`, `Minor → Minor`) and summed with the major-influence parent (`Minor + Minor = Major`; `Minor + Major` gives the value `3`, which the blood checks read as Major).
  - **Gold & base stats:** Gold = `2000 + floor((Mother.Money + Father.Money) / 10)`. Base stats = `floor((2 * Primary + Secondary) / 10) + floor((Level - 1) * TotalGrowth / 100)` (selected by child gender), adding `+15` to HP and `1..10` random Luck. Auto-promotes via `rlGetPromotedClassIfAvailable` if starting level qualifies.
  - **Inventory (`rlInheritInventoryToChild`):** Inherits from `MajorInfluence` parent's inventory and Supply. `Forseti`, `ValkyrieStaff`, and `Yewfelle` bypass rank/obtainability and the 7-item cap; other holy weapons are reverted; overflow past 7 items goes to child's Supply; the highest-Might weapon is placed in slot 1.

## Disassembly notes and anomalies

- **Retail-ROM bugs and quirks:**
  - **Jealousy bug (`factions.asm:1806–1816`):** `rsAddAdjacentLovePoints` overwrites `wSelectedUnitDataRAMPointer` to inspect candidate unit `X` and branches away without restoring it from `Y` when `X` is female (`GenID >= $10`), awarding subsequent `+5` adjacency points to the adjacent woman.
  - **Out-of-bounds loop in `rsInitUnitLoverData` (`unit_creation.asm:547–563`):** Loops 16 times (`wR0 = $10`) over 15 male entries (`$7E/2000`–`$7E/201C`).
  - **Wrong register in `rsDebugGetItemSkills` (`skills.asm:441`):** Executes `tya` instead of `txa` before `rlCheckIfWeaponEquipped`.
  - **Faction bugs (`factions.asm`):** `rsSetFactionSlotsHostilityEnemies` (`:1470`) lacks `bcs _End` after `cmp #7`; `rlUnloadFactionSlot` (`:258`) checks `cmp #$0080` instead of `$FFFF`; `rlLoadFactionGroup` (`:146`) writes 16 bits into `LocationID` before checking `$FFFF`, spilling into `HostileFactions`; `rlRemoveSelectedUnitFromFactionSlot` (`:1120`) decrements `UnitCount` even if the unit is not found; `rlCountFactionFieldedLivingUnits` (`:759`) clobbers `wSelectedUnitDataRAMPointer` and `wRoutineVariable1`.
  - **Weapon rank early exit (`unit_info.asm:262–269`):** A higher-index Minor Holy Blood that upgrades `B → A` returns `CLC` immediately without checking lower-index Major Holy Bloods.
  - **Asymmetric buffer save/load:** `rlSavePersonalCharacterDataToBuffer` omits `LoveDataID`, `rlSaveExtendedCharacterDataToBuffer` omits `LeadershipStars`, and `rlSaveCharacterROMDataToBuffer` omits `GenerationID`, whereas all three `rlLoad*FromBuffer` routines write them back.
  - **16-bit writes to byte fields/tables:** `aDebugMenuSkillFlags` clear (`skills.asm:295`) writes 1 byte past the 30-byte array; `rlGetPromotedClassIfAvailable` (`classes.asm:52`) writes 16 bits to `$7E/2002`; `rlFillChildExtendedPersonalData` (`inheritance.asm:146`) adds Luck in 16-bit mode; `rlRemoveFromUnitJoinOrder` (`join_order.asm:58`) stores 16 bits into a 1-byte entry.
- **Remaining disassembly notes:**
  - `aDebugMenuSkillFlags` scratch aliasing in `turn_start.asm:380`, hardcoded `$830000`/raw offsets, and unused stubs (`rlDoNothing84B4C3`, `rlStatsUnusedStub1`/`2`, `rlSetSelectedUnitAIUnused`).
