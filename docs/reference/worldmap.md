# The world map

Between chapters, and in the epilogue, the game shows a map of Jugdral. Event scripts tell the story on it: they scroll the map, place markers for armies, show portraits, highlight regions and print dialogue. The world map screen is game states `$0D`-`$0F`. Its pieces are in [engine/worldmap/](../../engine/worldmap/), and the commands that drive it are event commands (`rsEventCommandWM*` in [event_scripts.asm](../../engine/events/event_scripts.asm)). The chapter intro title card after it is in the same folder. Per-routine details: [routines/worldmap.md](routines/worldmap.md) (generated by `tools/reference.py`).

## Files

| File | Responsible for |
|---|---|
| [world_map.asm](../../engine/worldmap/world_map.asm) | The screen: setup and VBlank (bank `$80`); the game states, the steps and each frame; the sprite colour cycle; the two IRQs and the layer HDMA (bank `$8B`). |
| [markers.asm](../../engine/worldmap/markers.asm) | Markers (the army icons) and their shadows, with the shadow fade procs and the marker sprites. |
| [portraits.asm](../../engine/worldmap/portraits.asm) | Up to seven portraits on the map: loading, fading, moving. |
| [highlight.asm](../../engine/worldmap/highlight.asm) | Lighting up one region of the map (Verdane, Agustria, ...). |
| [chapter_intro.asm](../../engine/worldmap/chapter_intro.asm) | The chapter title card that follows the world map. |
| [engine/debug/world_map_test.asm](../../engine/debug/world_map_test.asm) | An unreachable test mode for the world map. |

RAM: `aWorldMapMarker` (`$7F5400`) and `aWorldMapPortrait` (`$7F5450`), `aPortraitSlotsPaletteBuffer` (`$7F5599`) and `wWorldMapLayersDialogueStatus` in [WRAM.h](../../include/WRAM.h). The epilogue's world map texts are in [text/dialogue/EpilogueWorldMap](../../text/dialogue/EpilogueWorldMap).

## How it runs

1. An event's `WM_FADE_IN` command (`rsEventCommandWMFadeIn`) fades out to `rsSetupWorldMapScreen`. That routine resets the screen and the engines and adds the two IRQs. It sets game states `$0E` (setup) and `$0D` (upkeep), installs `rsWorldMapVBlank`, and loads the graphics (`rlInitWorldMapGraphics`).
2. `rlWorldMapSetup` (`$0E`, once) clears the world map RAM (`$7F4400`-`$7F5708`) and turns on sprites. It then moves on to `rlWorldMapStep` (`$0F`) at step 0, with step 1 to follow.
3. `rlWorldMapStep` runs a step from `aWorldMapStepHandlers`:
   - 0, `rsWorldMapStepFadeIn`: brightens one level every 8 frames, then step 1.
   - 1, `rsWorldMapStepRun`: the frame. In the epilogue it also counts frames in `wEpilogueRecordCharacter`, which the epilogue's ASMCs compare.
   - 2, `rsWorldMapStepFadeOut`: darkens one level every 8 frames. Nothing found selects it.
4. Each running frame (`rlWorldMapRunFrame`): Start skips to the chapter intro, except in the epilogue. Then the portraits and markers move and fade, the dialogue's arrows and text are drawn, and colour 5 of sprite palettes 1 and 2 cycles from orange to pale yellow (`rsCycleWorldMapSpriteColors`).
5. `rlWorldMapUpkeep` (`$0D`, every frame) copies the map's scroll to BG1 and BG3.
6. The event's `WM_FADE_OUT` (`rsEventCommandWMFadeOut`) fades to the chapter intro. In the epilogue it goes to the credits instead (`rlStartEpilogueCredits`).

**The edges.** BG2 has two tilemaps: the map at `$5400` and the panel below it at `$4C00`. An IRQ at line 0 (`rlWorldMapTopEdgeFadeIn`) switches BG2 to the map and raises the brightness over 8 lines, so the top edge fades in from black. An IRQ at line 160 (`rlWorldMapBottomEdgeFadeOut`) fades back to black over 8 lines and switches BG2 to the panel. An HDMA table on TM (`rlWorldMapBuildLayersHDMATable`) picks the layers by line. BG3, the text, is shown in the panel only while a dialogue is up.

## Leftovers

- `procWorldMapMarkerShadow2FadeIn` and its fade-out are a second copy of the marker shadow fade, on BG palette 5. Nothing creates them.
- The world map test mode ([world_map_test.asm](../../engine/debug/world_map_test.asm)) moves a cursor and scrolls the map with the control pad. Each button does a test action: load portraits, highlight a region, open a dialogue box, return to the map with Select. Nothing reaches it. `rsUnusedWorldMapTestShowPortraits` beside it is unreachable too.
